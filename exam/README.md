# TypeScript技術認定試験 対策

本編 24 章を終えたあとの、資格試験対策用の模試。
本番と同じ形式で出題し、分野別の弱点と復習すべき章を返す。

## 本番の形式

| 項目 | 内容 |
| --- | --- |
| 出題形式 | 多肢選択式（四肢択一） |
| 問題数 | 35 問 |
| 試験時間 | 60 分 |
| 合格基準 | 正答率 70%（35 問中 25 問） |
| 出題範囲 | 基本文法 / データ型 / クラスとオブジェクト / 関数 / 制御構造 / 応用文法 の 6 分野 |
| 受験料 | 7,800 円（税込） |
| 実施 | 通年。全国のテストセンターまたはオンライン受験 |

出典は[主催団体の案内](https://cbttesting.com/typescript/)と
[受験ポータル](https://cbt-s.com/examinee/examination/typescript.html)。
**申し込む前に必ず最新の情報を公式で確認すること。** ここに書いた条件は変わりうる。

## 使い方

```bash
npm run exam                    # 本番形式（35問 60分、合否判定つき）
npm run exam -- --count 10      # 短く回す（時間制限なし）
npm run exam -- --field class   # 分野を絞って練習
npm run exam -- --review        # 過去に間違えた問題だけ
npm run exam -- --stats         # これまでの成績と分野別の通算
npm run exam -- --validate      # 問題バンクの検査（CI でも実行）
```

1〜4 で解答し、`q` で中断する。1 問ごとに正誤と解説が出る。
中断しても、そこまでの解答で採点する。

結果は `exam/history.json` に追記される。`--review` はこの記録を読んで、
間違えた問題だけを出題する。

## 対策の進め方

1. **本編を終える。** 演習を解かずに模試だけ回しても、選択肢を覚えるだけで身につかない。
2. **まず 1 回、本番形式で通す。** 時間配分（1 問あたり約 100 秒）を体で知る。
3. **分野別の正答率を見る。** 70% を切った分野は、対応表の章に戻って `npm run check` からやり直す。
4. **`--review` で落とした問題を潰す。** 全問正解になるまで繰り返す。
5. **本番形式に戻る。** 2 回続けて 85% を超えたら、申し込んでよい頃合い。

## 問題を足す

`exam/questions/*.json` に追記する。1 ファイルが 1 分野。

```json
{
  "id": "datatype-11",
  "question": "問題文。コードは \n で改行する",
  "choices": ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
  "answer": 0,
  "explanation": "なぜそれが正解か。1〜2 文で",
  "ref": "第2章"
}
```

- `choices` はちょうど 4 つ。重複は不可（四肢択一のため）
- `answer` は正解の添字（0〜3）。**出題時に選択肢はシャッフルされる**ので、
  正解の位置が偏る心配は要らない
- `ref` は復習先の章。落とした問題から教材に戻れるようにするための欄
- `id` は全体で一意

追記したら `npm run exam -- --validate` で検査する。CI でも同じ検査が走る。

**解いて覚えるより、作って覚えるほうが速い。**
間違えた問題は、解説を読んだうえで自分の言葉で 1 問作り直すとよい。
