# TypeScript 独学カリキュラム

JavaScript は書けるが TypeScript は初めて、という前提で作った **手を動かす教材**です。
全 24 章。各章に解説・演習・自動採点があり、React までひと通り到達します。

---

## セットアップ

```bash
npm install
npm run check 01     # 第1章の採点（最初は赤くなります。それが出発点です）
```

Node.js 20 以上が必要です。

## 使い方

```
src/ch01-getting-started/
  README.md        ← まずこれを読む
  exercise.ts      ← TODO を埋める
  exercise.test.ts ← 仕様書でもある。読んでよい
solutions/ch01-getting-started/
  exercise.ts      ← 解答例（自力で 15 分粘ってから見る）
```

1. 章の `README.md` を読む
2. `exercise.ts` の `TODO` を埋める
3. `npm run check 01` で採点する
4. 全部緑になったら `solutions/` の解答例と自分のコードを見比べる

**3 と 4 の間に必ず「なぜ通ったか / なぜ通らなかったか」を言葉にしてください。**
エラーメッセージを読む力そのものが、この教材でいちばん身につけてほしいものです。

### コマンド

| コマンド | 内容 |
| --- | --- |
| `npm run check 05` | 第5章を採点（型チェック → テスト → Lint） |
| `npm run check 05 06` | 複数章まとめて |
| `npm run check` | 全章（進捗の確認用。未着手の章は赤くなります） |
| `npm test` | テストだけ実行 |
| `npm run test:watch` | 保存のたびに再実行（演習中はこれが快適） |
| `npm run typecheck` | リポジトリ全体の型チェック |
| `npm run lint` | ESLint（第23章の `lint-me.ts` は、直すまでエラーが 4 件出ます） |

### 2 種類の演習

- **実行時の演習**: テストが緑になれば正解
- **型レベルの演習**: `Expect<Equal<...>>` と書いてあるもの。**tsc のエラーが消えたら正解**

型レベルの演習は「実行」されません。コンパイルが通ること自体が答え合わせです。

## 学習ペースの目安

| ペース | 1 日 | 完走まで |
| --- | --- | --- |
| じっくり | 1 章（60〜90 分） | 約 4 週間 |
| 標準 | 2〜3 日で 2 章 | 約 6 週間 |
| 週末型 | 土日に 3 章 | 約 8 週間 |

**飛ばしてよい章はありません**が、急ぐなら 12・13 章（型レベルプログラミング）は
「読むだけ」にして先に進み、あとで戻ってきても構いません。実務での使用頻度が低めだからです。

逆に **9 章（判別可能なユニオン）と 14 章（satisfies）は必ずやってください。**
この 2 つが、TypeScript を「書けている」と「使えている」の分かれ目です。

## 外伝（ex01〜ex06）— 「やるな」と思われる技

本編を終えた人向けの応用編です。**知らなくても書けるが、知っていると一段うまく書ける**
テクニックを集めました。順番はどこからでも構いません。

| 章 | テーマ | 扱うもの |
| --- | --- | --- |
| ex01 | 推論を操る | `NoInfer<T>`、`const` 型引数、型引数の部分適用 |
| ex02 | ユニオンを自在に操る | 対応表からユニオン生成、`DistributiveOmit`、`UnionToIntersection`、XOR props、`as const satisfies` |
| ex03 | 可変長タプルと関数型 | シグネチャを保つラッパー、`bindFirst`、タプルを保つ Mapped Type、`pipe` の型 |
| ex04 | 型で状態機械を作る | ファントム型、`this` 条件型ビルダー、polymorphic `this`、`asserts this is`、`unique symbol` ブランド |
| ex05 | 開発体験を上げる小技 | `Prettify`、filter の絞り込み、型付き `Object.keys`、型でエラーメッセージ、`using` |
| ex06 | 記法カタログ | 変性注釈 `in`/`out`、テンプレートリテラルのキー、getter/setter 別型、`infer extends`、`abstract new`、インスタンス化式 |

```bash
npm run check ex04       # 外伝の採点も同じコマンド
```

外伝の演習には **`@ts-expect-error` による採点**が混ざっています。
「エラーになるはずの行」がエラーにならないと、その行自体がエラーになる仕組みです。
型がゆるいままだと通らないので、**厳密に書けているかの自動チェック**になります。

## この教材のバージョン方針

TypeScript は **5.9 系**に固定しています。TypeScript 7 は公開されていますが、
`typescript-eslint` がまだ対応していないためです（Lint を学習に含めたいので 5 系を採用）。
最新版で学びたい場合は次で切り替えられます。Lint は動かなくなります。

```bash
npm i -D typescript@latest     # 型チェックとテストはそのまま動きます
```

**この「ツールチェーンのバージョンがずれる」こと自体、TypeScript を使う上での現実です。**
第23章で扱います。
