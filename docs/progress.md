## 記録の付け方

```bash
npm run check 04        # 緑になったら採点して、この表の 04 の行を埋める
```

テスト数は採点時の `Tests N passed` の N。型レベルだけの演習は実行時テストを持たないので、
`✅ 型チェック OK` が答え合わせそのものになる（第12章など）。

**採点は緑になった直後にやること。** 何点だったかより、
「なぜ引かれたか」を一行で書き残すほうが効く。
