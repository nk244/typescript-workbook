## 記録の付け方

```bash
npm run check 04        # 緑になったらこの表の 04 の行を更新する
```

テスト数は採点時の `Tests N passed` の N。型レベルだけの演習は実行時テストを持たないので、
`✅ 型チェック OK` が答え合わせそのものになる（第12章など）。

解いた直後に **「なぜ通ったか / なぜ通らなかったか」** をメモ欄に一行残しておくと、
あとで見返したときに効く。
